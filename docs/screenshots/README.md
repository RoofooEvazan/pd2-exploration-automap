# Gameplay screenshots

Campaign and endgame examples of the exploration automap. The latest Spider Forest and Poisoned Well screenshots show both the full-screen overlay and corner minimap. Gray outlines describe the explored terrain; red edges mark unfinished exploration. Campaign views also retain native water patterns and navigation artwork.
